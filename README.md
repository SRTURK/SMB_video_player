# 简映 SMB

精简安卓远程视频播放器，Android 8.0 及以上可运行。

## 下载

从本仓库 Releases 下载最新版 APK。首次启动不预填服务器地址；账号密码仅保存在手机应用私有存储中。

## 使用

1. 手机和电脑需处于可互通的局域网或 Tailscale 网络。
2. 输入电脑 IP，留空共享名称即可请求共享列表；也可指定共享名称直接进入。
3. 有账号保护的 Windows 共享需填写 Windows 用户名和密码，PIN 不能代替密码。
4. 点击文件夹逐层浏览，只显示文件夹和视频格式文件。左侧优先展示视频封面，右侧文件名最多两行，超出省略。
5. 点击视频播放，底部显示时间、进度条，按钮从左到右为旋转、上一个视频、播放／暂停、下一个视频、倍速。上下视频遵循当前文件夹的排序、跳过文件夹；首尾按钮禁用，不循环。顶部只保留返回和标题，移除 Media3 默认控制面板。单击视频显示／隐藏控件，播放中约 3.5 秒后自动隐藏。系统状态栏和导航栏在播放时隐藏；从屏幕边缘滑动可临时唤出。视频保持原比例，已移除填满和中央加载转圈。双击暂停／恢复；长按临时 3 倍速，松开恢复且不显示提示。左右滑动调整进度，左侧上下滑动调亮度，右侧调音量；手势提示缩小、上移、降低背景不透明度。
6. 默认勾选“记住密码，下次打开自动连接”。连接成功后保存加密凭据；启动时尝试一次上次连接，失败会显示连接表单，可修改后重试。右上角菜单 → 连接设置可清除密码。
7. 支持名称自然排序、修改时间、大小，均可选择升序或降序；文件夹始终优先。点击列表上方排序入口或右上角菜单修改。

8. 返回上级目录复用本次连接中的目录快照并恢复列表位置；需要同步电脑新增／删除的文件时，右上角选择“刷新文件夹”。最多保留 64 个目录快照，重新连接会清除快照。
9. 浏览停稳后预加载后续 8 个视频封面、附近 2 个文件夹；空闲时逐个补齐当前文件夹的封面。播放期间仅在播放器停止缓冲且缓存足够（约 15 秒实际播放时间）或暂停／播完后尝试，重新缓冲时中止封面读取；后台不预加载。

SMB 不传输 Windows 资源管理器的视图排序设置，所以手机端单独排序，保留原目录层级。自然排序支持数字及中文比较，但 Windows 不同地区设置下的标点、混合语言顺序可能有差异。

## 边界

- SMB 2.02/2.1，禁用 SMB1。当前不支持要求 SMB3 加密的服务器。此次优化集中于目录缓存、封面预加载和合并请求；没有启用当前 jcifs-ng 中实验性的 SMB3。缓存命中可省去网络读取，不保证提升网络本身的吞吐量。
- 只读访问；视频按需读取，支持随机定位，不先下载完整视频。
- 密码使用 Android Keystore 的 AES-GCM 密钥加密后写入应用私有存储，密钥不导出；服务器、用户名、排序、倍速和进度保存在应用私有目录。禁用系统备份及设备迁移。卸载、清除数据或密钥失效后需重新输入密码。
- 封面与文字区域按 4:6 分配；封面后台提取，优先内嵌封面及视频关键帧。最多并行两个任务，当前可见封面优先，重复任务合并；每个任务带 8 MB 随机读取缓存，图片内存缓存约 12 MB，私有磁盘缓存约 32 MB。网络失败可自动重试一次，也可刷新重新加载。不支持的视频仍显示占位图，不阻止播放。每次提取最多约 64 MB、45 秒（正在进行的网络请求受 SMB 超时约束），避免无限读取。
- 音视频解码由 Media3 和手机系统解码器提供，不能保证 MX Player 的全部格式覆盖，尤其 DTS、部分 AC3 或特殊编码。支持播放器识别的内嵌字幕，暂未实现外挂字幕。
- 切到后台暂停；不提供后台音频服务、广告、推荐、视频库扫描或云同步。
- 共享枚举可能被服务器策略禁止，此时可填写已知共享名称直连。

## 构建

安装 JDK 21、Android SDK 36 extension 20、Build Tools 36.x。创建 `local.properties` 指向本机 SDK：

```properties
sdk.dir=C:/Users/YOUR_NAME/AppData/Local/Android/Sdk
```

使用 Gradle 9.4.1：

```text
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

代码为 Java 17，AGP 9.2.1。依赖版本固定以复现此次构建，不表示使用最新版本。

## 开源组件

- AndroidX Media3 1.3.1（Apache-2.0）：https://github.com/androidx/media
- jcifs-ng 2.1.10（LGPL-2.1）：https://github.com/AgNO3/jcifs-ng
- SLF4J 1.7.36（MIT）：https://www.slf4j.org/

此目录提供完整应用源码和可重新构建的 Gradle 配置。分发应用时应保留第三方许可，并遵守 jcifs-ng 的 LGPL 条款。此版未混淆，可修改依赖后重新构建。

## 真机回归

`lab` 构建使用独立包名 `cn.lanvideo.app.lab`，避免覆盖正常应用的连接信息。

```text
./gradlew -PdeviceLab :app:assembleLab :app:assembleLabAndroidTest
```

安装对应 APK 后运行 AndroidJUnitRunner；传入 `smbTestFile` 参数可执行真实 SMB 读取、封面、播放及倍速测试。不传该参数时网络相关测试会跳过。完整 UI 回归使用本机只读合成 SMB 服务，通过 `adb reverse tcp:1445 tcp:1445` 暴露到手机；路径为 `smb://127.0.0.1:1445/fixture/Season1/第2集 # 100%.mp4`，传给测试时需对文件名进行 URL 编码。测试视频应为 640×360、20 秒的 H.264/AAC MP4。测试源码位于 `app/src/androidTest`。

若使用 scrcpy 投屏且希望声音从手机播放，用 `scrcpy --no-audio` 启动投屏。它默认转发手机音频到电脑。

## 播放手势（0.3.0）

- 长按视频画面：临时切到 3 倍速；松手、取消触摸或切到后台时恢复原倍速，不改保存的速度。
- 左右滑动：预览快退／快进位置，松手后才执行定位；整屏滑动最多约 120 秒，目标位置限制在视频范围内。
- 左半屏上下滑动：调整当前播放窗口亮度，退出播放恢复原亮度，不修改系统全局亮度。
- 右半屏上下滑动：调整手机媒体音量。
- 进度条及按钮区域保留原有触摸行为，不触发画面手势。

## 发行构建

签名由环境变量 `ANDROID_SIGNING_STORE_FILE`、`ANDROID_SIGNING_STORE_PASSWORD`、`ANDROID_SIGNING_KEY_ALIAS`、`ANDROID_SIGNING_KEY_PASSWORD` 提供，再运行 `gradlew :app:assembleRelease`。不要提交私钥或包含凭据的配置文件。升级安装须使用同一签名；本次发行沿用原安装包签名以保留已有配置，发行 APK 不可调试。

可复用测试工具见 [tools/README.md](tools/README.md)。本地 `artifacts/` 保存发行文件，`signing/` 和 `.tools/` 是不上传的本机材料；构建输出、临时片源和日志均不进入 Git。
